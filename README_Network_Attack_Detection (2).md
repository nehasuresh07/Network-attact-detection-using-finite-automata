# Detection of Network Attack Patterns Using Finite Automata

A Google Colab / Python classroom prototype based on the Formal Language and Automata project report.

## Implemented
- Directory traversal detection using a DFA
- SQL injection signature matching using Aho–Corasick
- SYN-flood style detection using a bounded-state machine
- Port-scan detection using a bounded counter
- Synthetic test cases

## Run
Open `Network_Attack_Detection_Finite_Automata.ipynb` in Google Colab and choose **Runtime → Run all**.

This is a defensive educational prototype using synthetic inputs. It does not capture live network traffic or claim benchmark performance on a public dataset.
